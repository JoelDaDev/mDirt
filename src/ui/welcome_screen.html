mDirt

Minecraft Datapack Editor — making datapacks easy.

Getting Started

  • Click New Project to create a datapack project
  • Add Blocks, Items, Recipes, and more from the sidebar
  • Click Export to generate your datapack and resource pack ZIPs

Features

  • Custom blocks, items, paintings, structures, and equipment sets
  • Visual crafting, smelting, and stonecutting recipe editors
  • Text component and potion command generators
  • Drag-and-drop texture import
  • Auto-save and workspace management
